# Theme picker mockup

The picked direction for the site theme picker: **C, Presets**. Presets first, then four core colours (accent, background, text, danger); the other 23 tokens in `theme.json` are derived from them, and all 27 stay editable under "Advanced".

- `Presets.dc.html` is the contract: its `data-duro` attributes name the Duro components, and every colour, size and spacing is a `var(--duro-*)` token. It loads `./support.js`, the Duro mockup seed, which is not shipped in this repository.
- `canvas.html` is the same artboard as one self-contained page. Open that one to look at it. It is generated by `duro mockup canvas`: regenerate it, never edit it.

Finding from the mockup: `theme.json` does not set the `active*` tokens, so a pressed toggle would render in the stock blue. The picker has to cover them or derive them from the accent.
